## About me

I'm a Java Developer with 4+ years of professional experience.

I work on systems where reliable integrations, clear service boundaries, and predictable behavior in production matter. I enjoy turning complex business processes into maintainable services and taking changes through the full development lifecycle — from clarifying requirements and designing APIs to testing, deployment, observability, and production support.

## What I work on

- Designing and developing microservices with Java 17/21 and Spring Boot
- Building REST APIs and versioned integration contracts
- Building asynchronous workflows with Kafka and RabbitMQ, with an emphasis on idempotency, controlled retries, and transactional outbox where appropriate
- Working with relational databases, automated testing, monitoring, logging, and production diagnostics

## Selected project highlights

- **Digital insurance platform:** implemented versioned API workflows based on a company-wide canonical API contract for motor insurance products. According to team estimates, this reduced onboarding time for new products from **4–6 weeks to 1–2 weeks** and the number of product-specific integrations by approximately **30%**.

- **Home assistance service:** built a Java 21 backend service from scratch as the sole developer, working directly with business stakeholders. The service moved approximately **200 requests per day** from manual call-center processing to a mobile flow and reduced request creation time from **10–15 minutes to under 1 minute**. Transactional outbox and idempotent Kafka processing were used, with no recorded cases of lost or duplicate requests after launch.

- **Credit decisioning platform:** helped extract credit strategies from a monolith into independently deployable services, reducing the lead time for launching a new strategy from **10 to 3 business days**. Contributed to API Gateway adoption, associated with approximately **40% fewer direct integration routes**, and to delivery-pipeline improvements that shortened the release window by approximately **60%**.
